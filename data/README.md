# Dataset acquisition

The analysis uses the **South German Credit** dataset from the UCI Machine Learning Repository (dataset ID 522).

- Dataset page: https://archive.ics.uci.edu/dataset/522/south+german+credit
- DOI: https://doi.org/10.24432/C5X89F
- 1,000 instances
- Finance / credit-risk classification

Run `python data_analysis.py`. On first run, `ucimlrepo` downloads the dataset and saves `south_german_credit.csv` locally.
